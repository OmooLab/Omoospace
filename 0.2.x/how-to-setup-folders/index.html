    如何设置文件夹？

    示例

    细菌奥秘
├── contents/
│   ├── images/
│   │   ╰── 噪波贴图.png # 被引用的贴图
│   ├── models/
│   │   ├── 网上找的模型/
│   │   │   ├── 网上找的模型.fbx
│   │   │   ╰── textures/
│   │   │       ├── 网上找的模型.color.png
│   │   │       ╰── 网上找的模型.roughness.png
│   │   ╰── 大肠杆菌.blend # 原工程文件的副本
│   ╰── renders/
│       ├── 大肠杆菌游动.mp4 # 直接渲染成动画
│       ├── 如何引起感染_Seq010/ # 序列帧用文件夹
│       │   ╰── 如何引起感染_Seq010.####.png
│       ├── 如何引起感染_Seq010.v001 # 复制的备份
│       │   ╰── 如何引起感染_Seq010.####.png
│       ╰── 如何引起感染_Seq020/ # AOV 也放里头
│           ├── 如何引起感染_Seq010.####.png
│           ╰── 如何引起感染_Seq010.aov1.####.png 
├── subspaces/
│   ├── 大肠杆菌/ # （建模）大肠杆菌
│   │   ├── 大肠杆菌.blend # 最新版本
│   │   ├── 大肠杆菌.马南.blend # 马南的分支
│   │   ╰── 大肠杆菌.v001.blend # 备份版本
│   ├── 大肠杆菌游动/ # 简单的短片
│   │   ├── 大肠杆菌游动.blend # （搭建）大肠杆菌游动
│   │   ╰── 大肠杆菌游动.prproj # （剪辑）大肠杆菌游动
│   ╰── 如何引起感染/ # 复杂的动画
│       ├── 如何引起感染.prproj
│       ├── Seq010.blend # Subspace 可以是单文件
│       ╰── Seq020/ # Subspace 也可以是文件夹
│           ├── Seq020.blend
│           ╰── 测试聚集特效.hip
